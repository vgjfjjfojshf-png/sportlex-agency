# SportLex — Sports Law & Talent Agency

Hybrid sports law agency website: Women's Football + Sports Law + Esports.

## Stack
- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- next-intl (AR + EN, RTL support)
- React Hook Form + Zod
- Resend (contact form emails)

## Setup

```bash
npm install
cp .env.example .env.local
# Add your RESEND_API_KEY and CONTACT_EMAIL
npm run dev
